# Reference run of params_zpz_decay.txt with lambda = 0: the same real psi,
# binary, grid and seed of phi2, but no coupling, so phi1 evolves as a free
# field and phi2 stays at the seed. Compare its data/rho_integrals.dat (rho1
# inside r < 40) with the coupled run to measure how much of the cloud the
# decay psi -> phi phi removes.
#
# The rest of this header is the one of params_zpz_decay.txt.
#
# The cubic coupling of params_zpz_channel.txt with the square on the other
# field, V_int = -lambda phi1 phi2^2 (interaction_squared_field = 2), so that
# the dark matter field psi = phi1 can decay, psi -> phi phi with phi = phi2.
#
# Everything except the fields is params_zpz_channel.txt: the binary of
# Bamber et al. (d ~ 12.2 M), L = 512, G_Newton = 0 (test fields on the
# vacuum binary), stop_time = 1620, rho_integral_radius = 40, and psi with
# mu1 = 0.34 and psi0 = sqrt(2) (rho0 = mu1^2 as their complex field).
#
# Field equations:
#   (Box - mu1^2) phi1 = -lambda phi2^2,
#   (Box - mu2^2) phi2 = -2 lambda phi1 phi2.
# With phi2 = 0 the right hand sides vanish and phi2 stays exactly zero, so a
# small seed is added (phi2_noise_*). The oscillation psi = psi_l cos(mu1 t)
# then modulates the mass of phi2, mu2^2 - 2 lambda psi_l cos(mu1 t), and
# the modes with omega_k = mu1 / 2, i.e. |k| = sqrt(mu1^2 / 4 - mu2^2), grow
# by parametric resonance (two phi2 back to back carry the momentum, so
# unlike psi psi -> phi in params_zpz_channel.txt this also happens in the
# uniform background) at the rate
#   s ~ lambda psi_l / mu1 = g A / mu1,  g = lambda psi0, A = psi_l / psi0.
# This needs mu2 < mu1 / 2. Here mu2 = 0.16 (q = 0.47): |k| = 0.057
# (wavelength ~ 110), group velocity ~ 0.34. With g = 1e-3:
#   background (A = 1): s = 2.9e-3, about 4.8 e-folds by t = 1620;
#   cloud (A ~ 8):      s = 2.4e-2, but the modes leave a region of radius
#                       ~20 in ~60 M, so the growth there is limited.
# Closer to q = 0.5 the modes are slower but longer (q = 0.49: |k| = 0.034,
# v = 0.2). phi2 becomes tachyonic where 2 lambda psi_l > mu2^2, i.e.
# g A > mu2^2 / 2 = 0.0128 (A > 13 for g = 1e-3).
#
# The seed has rms 1e-2 (relative 7e-3 to psi0, energy ~2e-5 rho0) and covers |k| in
# [0.02, 0.12] around the resonance; it is not included in rho and K, which
# do not matter for G_Newton = 0 anyway.
#
# Suggested runs (compare data/rho_integrals.dat, rho1 and rho2):
#   1. lambda = 0: reference, the same as params_zpz_channel.txt with
#      lambda = 0;
#   2. this file (g = 1e-3), and g = 2e-3 (lambda = 1.41421e-3);
#   3. each of them without the BHs (massA = massB = 1e-12, tiny momenta,
#      track_punctures = 0): the decay of the background alone. The binary
#      matters only if rho1 around it drops more than in this control.
#   4. mu2 = 0.18 > mu1 / 2: decay forbidden, nothing should happen.
#
# See the wiki page for an explanation of the params!
# https://github.com/GRChombo/GRChombo/wiki/Guide-to-parameters
# and a guide to this specific example at
# https://github.com/GRChombo/GRChombo/wiki/Running-the-BBH-example
