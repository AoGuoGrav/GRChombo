# Effect of the cubic coupling of Zhu, Piao & Zhang [arXiv:2509.10892],
# L_int = lambda psi^2 phi, on the accumulation of a scalar field around the
# binary of Bamber et al. [arXiv:2210.09254].
#
# Everything except the fields is params_bamber_fig1.txt: the same binary
# (d ~ 12.2 M, T ~ 271 M), grid (L = 512), boundary conditions, G_Newton = 0
# (test fields on the vacuum binary), stop_time = 1620 (6 orbits), plot files
# every t = 60 and rho_integral_radius = 40. psi = phi1 has their mass
# mu1 = 0.34 and the same background density rho0 = mu1^2 = 0.1156 as the
# complex field there: psi0 = sqrt(2), Pi1_0 = 0 (rho0 = 1/2 mu1^2 psi0^2).
# phi = phi2 starts empty. So rho1 / 0.1156 is rho/rho0 of their Fig. 1 and
# the same VisIt settings apply.
#
# psi has to be real: the coupling needs phi as the second field, so psi
# cannot also be complex with two fields. The single field reference is
# therefore this file with lambda = 0, a real field with the same mu and
# rho0. params_bamber_fig1.txt checks the code against their complex field.
#
# Coupling: with G = 0 the field equations
#   (Box - mu1^2) psi = -2 lambda psi phi,  (Box - mu2^2) phi = -lambda psi^2
# depend on lambda and the amplitude only through g = lambda psi0 (rescale
# psi, phi by psi0), so psi0 = sqrt(2) loses no generality: a physical
# background psi0_phys corresponds to lambda_phys = g / psi0_phys. Here
# g = 2e-3, i.e. 2 g / mu1^2 ~ 0.03 in the background and ~0.3 where psi has
# grown by ~8 (their Fig. 1). phi1 becomes tachyonic where 2 lambda phi2 >
# mu1^2; phi2 ~ g psi^2 / |mu2^2 - 4 mu1^2| stays well below this for
# g < ~5e-3.
#
# Their mechanism: the psi cloud, oscillating at omega ~ mu1, sources phi at
# 2 omega; phi radiates this energy away only if q = mu2 / mu1 < 2 (their
# Eq. (29) and Fig. 7), while for q > 2 it only follows the source. Their
# paper is about the superradiant cloud of a single Kerr BH, treated
# perturbatively over ~1e6-1e9 M, which cannot be simulated directly; this
# run tests the same channel on the cloud that the binary accumulates.
#
# Suggested runs (same file, compare data/rho_integrals.dat, rho1 and rho2):
#   1. lambda = 0: the single field reference;
#   2. q = 1.5 (scalar_mass2 = 0.51, this file): channel open;
#   3. q = 2.5 (scalar_mass2 = 0.85): channel closed;
#   4. g = 1e-3 and 4e-3 (lambda = 7.07107e-4, 2.82843e-3) for the scaling.
# Expected if the mechanism holds: rho1 around the binary below the
# lambda = 0 run and rho2 growing for q = 1.5, much less so for q = 2.5.
#
# Resolution: mu2 = 0.51 (0.85) and the source at 2 mu1 = 0.68 are above the
# warning threshold 0.2 / coarsest_dx / dt_multiplier = 0.4, so the warning
# about mu2_eff is expected (~20 (15) time steps per period on the coarsest
# level). Check with dt_multiplier = 0.125 (twice the cost) that
# rho_integrals.dat does not change.
#
# See the wiki page for an explanation of the params!
# https://github.com/GRChombo/GRChombo/wiki/Guide-to-parameters
# and a guide to this specific example at
# https://github.com/GRChombo/GRChombo/wiki/Running-the-BBH-example
