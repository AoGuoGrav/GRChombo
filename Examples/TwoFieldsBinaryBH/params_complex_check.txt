# Cheap check of the TwoFieldsBinaryBH example against the complex scalar field
# runs of Bamber, Aurrekoetxea, Clough & Ferreira, PRD 107, 024035 (2023)
# [arXiv:2210.09254] (their homogeneous "H" initial data) and Aurrekoetxea,
# Clough, Bamber & Ferreira, PRL 132, 211401 (2024) [arXiv:2311.18156].
#
# With lambda = 0 and mu1 = mu2 = mu the two real fields are a complex field
# Phi = phi1 + i phi2, and phi1 = phi0, Pi1 = 0, phi2 = 0, Pi2 = mu phi0 is
# their uniform state Phi ~ phi0 e^{+i mu t} (the sign of Pi2_0 only swaps
# particles and antiparticles). rho = mu^2 phi0^2 is then constant in time
# (rho1 and rho2 oscillate in antiphase at 2 mu, their sum does not), so
# data/rho_integrals.dat (column "int rho dV (total)") measures the growth of
# the cloud around the binary without the 2 mu oscillation of a real field.
#
# Real field run at the same density, to compare the accumulation of a real
# and a complex field (lambda = 0 in both, so phi2 stays zero):
#   phi1_0 = 5.0e-5, Pi2_0 = 0.0
# (rho = 1/2 mu^2 phi1_0^2 is the same on average and oscillates at 2 mu).
# This is also the lambda = 0 reference of params_wave_dm_comparison.txt.
#
# To make it cheap with respect to params_wave_dm_comparison.txt:
#  - L = 256 instead of 512 (still 2 Compton wavelengths beyond the extraction
#    sphere) and N_full = 128, so the coarsest dx = 2 is the same and mu is
#    resolved there, with 8 times fewer cells on the coarsest level;
#  - finest dx = 1/32, twice the one of params.txt (BHs less resolved);
#  - stop_time = 1100 (about 4 orbits of the ~10 before merger), enough for
#    the overdensity to form, no merger;
#  - no AH finder, one extraction radius.
# Rerun with params_wave_dm_comparison.txt for production results.
#
# See the wiki page for an explanation of the params!
# https://github.com/GRChombo/GRChombo/wiki/Guide-to-parameters
# and a guide to this specific example at
# https://github.com/GRChombo/GRChombo/wiki/Running-the-BBH-example
