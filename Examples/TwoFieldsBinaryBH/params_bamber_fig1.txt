# Reproduction of Fig. 1 of Bamber, Aurrekoetxea, Clough & Ferreira,
# PRD 107, 024035 (2023) [arXiv:2210.09254]: Re[phi] and the energy density of
# a complex scalar field around the binary at t = 0, 540, 1080 and 1620 M
# (0, 2, 4 and 6 orbits), on the z = 0 plane for |x|, |y| < 60 M.
#
# Setup as theirs: the same equal mass binary as params.txt (d ~ 12.2 M,
# T ~ 271 M), mu = 0.34, L = 512, a complex field phi1 + i phi2 that is
# initially uniform, Phi = phi0 e^{i mu t} (lambda = 0, mu1 = mu2, Pi2_0 =
# mu phi0, see params_complex_check.txt), and no backreaction (G_Newton = 0),
# so that the field is a test field on the vacuum binary and K = 0.
# Since the field equation is then linear, phi0 = 1: phi1 is Re[phi]/phi0 of
# their top row and rho / mu^2 = rho / 0.1156 is rho/rho0 of their bottom row.
#
# Difference with their Fig. 1: theirs uses a fixed orbit binary background
# (their Sec. III), here the binary inspirals in full GR with the moving
# puncture gauge (their Sec. IV runs with G = 0). The orbit is close to the
# fixed one for the first orbits; by t = 1620 the binary is a few hundred M
# from merger, so the last snapshot differs most.
#
# Plot files are written every t = 60, so t = 540, 1080, 1620 are among them
# (cycles 1080, 2160, 3240). In VisIt: Slice z = 0.01, Project to 2D, window
# 196 316 196 316 (center 256 256), expressions phi1 (linear, -8 to 8) and
# if(gt(chi, 0.2), rho / 0.1156, 1) (log, 0.1 to 200).
# Each plot file is ~1.5 GB (28 files); check the disk quota first.
#
# See the wiki page for an explanation of the params!
# https://github.com/GRChombo/GRChombo/wiki/Guide-to-parameters
# and a guide to this specific example at
# https://github.com/GRChombo/GRChombo/wiki/Running-the-BBH-example
