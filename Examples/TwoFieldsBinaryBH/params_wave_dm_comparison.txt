# Parameters for the TwoFieldsBinaryBH example set up to compare with the
# wave dark matter binary simulations of Bamber, Aurrekoetxea, Clough &
# Ferreira, PRD 107, 024035 (2023) [arXiv:2210.09254] and Aurrekoetxea, Clough,
# Bamber & Ferreira, PRL 132, 211401 (2024) [arXiv:2311.18156]:
#  - same equal mass binary as theirs (and as params.txt): d ~ 12.2 M,
#    quasi-circular momenta, L = 512, extrapolating outer BCs for the fields;
#  - phi1 (the squared field psi of the cubic coupling of arXiv:2509.10892)
#    plays the role of their dark matter field, with mu1 = 0.34 as in Bamber et
#    al.; the PRL finds the largest effect for 2 pi / mu ~ d, i.e. mu ~ 0.5;
#  - phi2 has mass ratio q = mu2 / mu1 ~ 0.7 < 2, so that phi1 phi1 -> phi2
#    can radiate energy away, and starts empty (phi2_0 = 0);
#  - the grid is refined so that the Compton wavelength 2 pi / mu1 ~ 18 M is
#    resolved with ~37 points for r < 60 and ~18 points for r < 120 (the
#    extraction spheres, enlarged by 20%, are refined to extraction_levels).
# Differences with their setup: our fields are real (they use a complex field
# with Pi = -i mu phi0, whose density is stationary), and our amplitude is
# small (|K| stop_time ~ 0.23), so the backreaction on the orbit is tiny and
# the run measures the accumulation of the field, not the GW dephasing.
#
# Suggested runs: lambda = 0 (reference, accumulation as in their papers),
# lambda = 1, 4, 16, and each of them also without the BHs (massA = massB =
# 1e-12, tiny momenta, track_punctures = 0) to subtract the evolution of the
# homogeneous background. Compare data/rho_integrals.dat between them.
#
# For mu1 = 0.5 (2 pi / mu1 ~ d) set scalar_mass1 = 0.5, scalar_mass2 = 0.35,
# phi1_0 = 3.5e-5 and N_full = 352, which keeps mu1 resolved on the coarsest
# level and |K| stop_time ~ 0.24.
# See the wiki page for an explanation of the params!
# https://github.com/GRChombo/GRChombo/wiki/Guide-to-parameters
# and a guide to this specific example at
# https://github.com/GRChombo/GRChombo/wiki/Running-the-BBH-example
